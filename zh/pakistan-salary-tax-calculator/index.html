它如何计算

工资税按您的计算 年度 应税工资使用受薪级税档（工资超过应税收入的75%)，然后除以12 — 那是您的雇主每月根据第149条预扣的金额。

纳税年度 2026-27（《金融法》2026）： 高达Rs 600,000为0% · 高达Rs 1,200,000为1% · Rs 6,000 + 高达Rs 2,200,000为11% · Rs 116,000 + 高达Rs 3,200,000为20% · Rs 316,000 + 高达Rs 4,100,000为25% · Rs 541,000 + 高达Rs 5,600,000为29% · Rs 976,000 + 高达Rs 7,000,000为32% · Rs 1,424,000 + 以上为35%。第4AB条附加费不再适用于受薪人士。

纳税年度 2025-26（《金融法》2025）： 相同第一档，然后Rs 116,000 + 23%至Rs 3,200,000 · Rs 346,000 + 30%至Rs 4,100,000 · Rs 616,000 + 35%以上 — 加上 9% 收入超过Rs 10 million时税款的附加费。

工作例子：Rs 250,000/月 = Rs 3,000,000/年。TY 2026-27税 = Rs 116,000 + 20% × Rs 800,000 = 每年Rs 276,000 = 每月Rs 23,000。（在旧2025-26表上它将是Rs 300,000 — 新的中间档税率更低。）

常见问题

TY 2026-27工资税档是什么？

见上面“如何计算”中的表 — 与去年相比的标题变化是20%和25%中间档和35%最高税率之前的29%和32%两个新档。

工资还有附加费吗？

不 — 对于受薪人士，它从TY 2026-27起废除。在TY 2025-26中，它是收入超过Rs 10 million的税款的9%（不是10%：那是TY 2025，仍然是非受薪费率）。

每月Rs 100,000的税款？

每年Rs 1,200,000 → 每年Rs 6,000 → TY 2026-27中每月约Rs 500。

我应该选择哪一年？

2026-27是当前的（自2026年七月1日起生效）并且是默认。仅为去年的工资选择2025-26。

这些税档涵盖商业收入吗？

不 — 这些是受薪级税档（工资 > 应税收入的75%）。非受薪收入使用不同的表。

它如何运作 — 公式

计算器将您的月工资年化（× 12）并将全年通过您选择的税年的税档表运行，然后将年度税除以12得到第149条下的每月预扣。年选择器默认为 纳税年度 2026-27（《金融法》2026）：高达Rs 600,000为0% · Rs 0 + 高达Rs 1,200,000为1% · Rs 6,000 + 高达Rs 2,200,000为11% · Rs 116,000 + 高达Rs 3,200,000为20% · Rs 316,000 + 高达Rs 4,100,000为25% · Rs 541,000 + 高达Rs 5,600,000为29% · Rs 976,000 + 高达Rs 7,000,000为32% · Rs 1,424,000 + 以上为35%。在每个档中，税款是固定基数金额加上档内工资部分的档税率。税年2025-26使用旧的六档表（23%和30%中间档，Rs 4,100,000以上35%）并在年工资超过Rs 10 million时在税款上加9%附加费；2026-27表完全没有受薪附加费。

工作例子

工资每月Rs 300,000 = 每年Rs 3,600,000，税年2026-27。工资落在Rs 3,200,000–4,100,000档：税 = Rs 316,000 + 25% × Rs 400,000 = 每年Rs 416,000，所以每月预扣Rs 34,666.67，实得工资为每月Rs 265,333.33 — 有效税率11.56%。相同工资在2025-26表上将被征税Rs 466,000，恰好多Rs 50,000。

常见问题

我收到奖金或欠款 — 它们如何征税？

在计算之前将它们加入您的年工资。税档表适用于全年的总工资，所以大额一次性付款可以将该年收入的一部分推入更高档。

这包括EOBI、公积金或其他工资扣除吗？

不。此计算器仅计算所得税，所以所示净数字是您的工资减去所得税。任何EOBI或基金扣除在您的实际工资单中分开扣除。

有效税率是什么意思？

您的总税除以您的总工资。它总是低于您的最高档费率，因为您工资的较低部分按较低档费率征税 — 在上面的例子中，最高档是25%，但有效税率是11.56%。

旧附加费在非常高工资时有多大？

在每月Rs 1,000,000（每年Rs 12,000,000）时，税年2025-26给出Rs 3,685,290含Rs 304,290附加费，而2026-27给出Rs 3,174,000无附加费 — 每年差Rs 511,290。

我的工资在年中改变 — 我输入什么？

输入整个税年的总工资（将每个费率的月份加在一起）。税档适用于年度总计，这就是为什么此计算器首先以年度数字工作。

前Rs 600,000总是免税吗？

是，在本页两年中。0%档涵盖每个受薪人士的前Rs 600,000；1%税率仅适用于Rs 600,000和Rs 1,200,000之间的部分。
