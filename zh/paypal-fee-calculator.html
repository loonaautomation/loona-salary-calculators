它如何计算

PayPal对商业付款的费用是金额的一个百分比加上一个小的固定费用： 费用 = 金额 × % + 固定费用。按美国标准商业费率2.99% + $0.49，$100的付款费用为$3.48，因此您收到$96.52。要在扣除费用后恰好得到某个金额，您必须反向计算 — “gross-up”： 要请求的金额 =（您想要的金额 + 固定费用）÷ (1 − % ÷ 100).

常见问题

PayPal接收款项的标准费用是多少？

对于美国商业交易 — 商品和服务的付款 — PayPal标准费率为金额的2.99%加上$0.49的固定费用。因此$100的付款给您留下$96.52。其他PayPal产品（结账、卡支付的发票、小额付款）和其他国家使用不同的费率；本计算器中的每个费率都可编辑。

我如何确保在PayPal费用后收到确切金额？

使用本计算器的第二种模式。它用公式（目标 + 固定费用）÷ (1 − 费用%）将金额向上调整，因此费用从请求金额中扣除，您的确切目标保留。对于美国标准费率下的$100，您请求$103.59 — 简单的“加3%”猜测会让您少约十美分。

为什么小额付款的费用超过3%？

因为固定的$0.49部分。在$5的付款上，费用是$0.49 + 约$0.15 — 接近付款的13%。付款越小，固定费用显得越大，这就是为什么本计算器始终并排显示费用和净额。

PayPal对国际付款收取什么费用？

国际商业付款在国内费率上加一个百分比（美国账户为1.5%），并且如果涉及货币转换，则在市场汇率上加几个百分点的转换利润。将额外百分比加到上方的费用字段来模拟它 — 例如2.99% + 1.5% = 4.49%，加上$0.49固定费用。

“朋友和家人”没有费用 — 我可以将其用于销售吗？

不。个人“朋友和家人”付款是用于相识的人之间的金钱，不是用于商品和服务；没有购买保护，使用它们来逃避商业销售的费用违反PayPal的规则，并可能导致账户被限制。本计算器使用适用于真实销售的商业费率。

它如何运作 — 公式

在“接收”模式下，计算器应用费用 = 金额 × 费用% ÷ 100 + 固定费用，然后净额 = 金额 − 费用。在“接收确切金额”模式下，它反转相同的公式：要请求的金额 =（目标 + 固定费用）÷ (1 − 费用% ÷ 100)，因此对该较大请求的费用恰好留下目标。结果四舍五入到两位小数显示，请求金额四舍五入到最接近的分 — 在分的边界上，费用可能差一分，结果表会诚实地显示。

常见问题

当我向买家退款时，PayPal会退还其费用吗？

一般不会 — 自PayPal政策变化以来，当商业付款退款时，原始交易费会被保留（有限的例外）。这使费用成为您的成本的一部分，即使在退货销售上也是如此，这也是卖家在定价前用这样的计算器核查数字的原因之一。

为什么我在gross-up模式下请求的金额看起来奇怪，比如$103.59？

因为费用是按请求金额本身收取的，包括补足部分。请求$103.00会留下费用也从中扣除：$103.00 − ($3.08 + $0.49) = $99.43。gross-up公式求解其费用恰好留下您的目标的确切金额。
