它如何計算

eBay的最終價值費有兩部分：一個 銷售總金額的百分比 （商品價格 + 您向買家收取的運費）加上固定的 每單費用。對於大多數類別，百分比為13.6%，當訂單總額為$10或以下時每單費用為$0.30，超過$10時為$0.40。評級為低於標準的賣家在百分比部分額外支付5%。

常見問題

eBay從銷售中抽取百分之多少？

對於大多數類別，eBay按銷售總金額的13.6%收取最終價值費 — 商品價格加上收取的運費 — 加上$10或以下訂單每單$0.30費用，超過$10的訂單為$0.40。某些類別（例如某些電子產品、媒體和服裝價格段）使用不同的百分比，這就是本計算器中的費率可編輯的原因。

為什麼有兩種不同的每單費用，$0.30和$0.40？

當銷售總金額為$10或以下時，eBay每單收取$0.30，當超過$10時每單收取$0.40。對於非常便宜的商品，這一差異在費用中佔很大份額，因此本計算器會根據您的訂單總額自動選擇正確的費用 — 如果eBay更改它們，兩個金額都可編輯。

低於標準賣家費是什麼？

如果您的賣家表現降至低於標準，eBay將最終價值費百分比增加5個百分點（因此13.6%變為18.6%），直到您的表現恢復。使用上方的賣家表現選擇器開啟它，檢視它在每次銷售上讓您付出多少。

eBay也對運費收取費用嗎？

是的。最終價值費百分比適用於銷售總金額，其中包括您向買家收取的運費 — 因此免運費刊登不能避免費用，百分比只是適用於商品價格。

我還需支付刊登（插入）費嗎？

大多數休閒賣家每月獲得免費刊登的限額（大多數沒有商店訂閱的美國賣家每月250個零插入費刊登），之後每個刊登約$0.35的插入費適用。本計算器涵蓋最終價值費，這是完成銷售時迄今為止最大的成本；推廣刊登廣告費是分開的，取決於您選擇的廣告費率。

它如何運作 — 公式

計算器首先彙總銷售總金額： 總額 = 商品價格 + 收取的運費。百分比費用 = 總額 ×（最終價值費% + 低於標準額外%，當開啟時）。每單費用是當總額 ≤ $10時的“最高$10”金額，否則為“超過$10”金額。總費用 = 百分比費用 + 每單費用，利潤 = 總額 − 總費用 − 您的商品成本 − 您的運費成本。結果四捨五入到兩位小數顯示。

常見問題

eBay費用也按銷售稅收取嗎？

在eBay向買家收取銷售稅的地方，最終價值費在許多美國州按包括該稅款的總額計算，因為費用基於銷售總金額。確切處理方式各不相同；如果它對您的利潤率重要，請將含稅總額作為商品金額加入並比較。

如果我的類別有不同的費率怎麼辦？

選擇“自定義費率”並將您類別的百分比輸入費率欄位 — 其餘的計算（每單費用、低於標準額外、利潤）完全相同。
