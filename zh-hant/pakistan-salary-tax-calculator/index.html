它如何計算

工資稅按您的計算 年度 應稅工資使用受薪級稅檔（工資超過應稅收入的75%)，然後除以12 — 那是您的僱主每月根據第149條預扣的金額。

納稅年度 2026-27（《金融法》2026）： 高達Rs 600,000為0% · 高達Rs 1,200,000為1% · Rs 6,000 + 高達Rs 2,200,000為11% · Rs 116,000 + 高達Rs 3,200,000為20% · Rs 316,000 + 高達Rs 4,100,000為25% · Rs 541,000 + 高達Rs 5,600,000為29% · Rs 976,000 + 高達Rs 7,000,000為32% · Rs 1,424,000 + 以上為35%。第4AB條附加費不再適用於受薪人士。

納稅年度 2025-26（《金融法》2025）： 相同第一檔，然後Rs 116,000 + 23%至Rs 3,200,000 · Rs 346,000 + 30%至Rs 4,100,000 · Rs 616,000 + 35%以上 — 加上 9% 收入超過Rs 10 million時稅款的附加費。

工作例子：Rs 250,000/月 = Rs 3,000,000/年。TY 2026-27稅 = Rs 116,000 + 20% × Rs 800,000 = 每年Rs 276,000 = 每月Rs 23,000。（在舊2025-26表上它將是Rs 300,000 — 新的中間檔稅率更低。）

常見問題

TY 2026-27工資稅檔是什麼？

見上面“如何計算”中的表 — 與去年相比的標題變化是20%和25%中間檔和35%最高稅率之前的29%和32%兩個新檔。

工資還有附加費嗎？

不 — 對於受薪人士，它從TY 2026-27起廢除。在TY 2025-26中，它是收入超過Rs 10 million的稅款的9%（不是10%：那是TY 2025，仍然是非受薪費率）。

每月Rs 100,000的稅款？

每年Rs 1,200,000 → 每年Rs 6,000 → TY 2026-27中每月約Rs 500。

我應該選擇哪一年？

2026-27是當前的（自2026年七月1日起生效）並且是預設。僅為去年的工資選擇2025-26。

這些稅檔涵蓋商業收入嗎？

不 — 這些是受薪級稅檔（工資 > 應稅收入的75%）。非受薪收入使用不同的表。

它如何運作 — 公式

計算器將您的月工資年化（× 12）並將全年透過您選擇的稅年的稅檔表執行，然後將年度稅除以12得到第149條下的每月預扣。年選擇器預設為 納稅年度 2026-27（《金融法》2026）：高達Rs 600,000為0% · Rs 0 + 高達Rs 1,200,000為1% · Rs 6,000 + 高達Rs 2,200,000為11% · Rs 116,000 + 高達Rs 3,200,000為20% · Rs 316,000 + 高達Rs 4,100,000為25% · Rs 541,000 + 高達Rs 5,600,000為29% · Rs 976,000 + 高達Rs 7,000,000為32% · Rs 1,424,000 + 以上為35%。在每個檔中，稅款是固定基數金額加上檔內工資部分的檔稅率。稅年2025-26使用舊的六檔表（23%和30%中間檔，Rs 4,100,000以上35%）並在年工資超過Rs 10 million時在稅款上加9%附加費；2026-27表完全沒有受薪附加費。

工作例子

工資每月Rs 300,000 = 每年Rs 3,600,000，稅年2026-27。工資落在Rs 3,200,000–4,100,000檔：稅 = Rs 316,000 + 25% × Rs 400,000 = 每年Rs 416,000，所以每月預扣Rs 34,666.67，實得工資為每月Rs 265,333.33 — 有效稅率11.56%。相同工資在2025-26表上將被徵稅Rs 466,000，恰好多Rs 50,000。

常見問題

我收到獎金或欠款 — 它們如何徵稅？

在計算之前將它們加入您的年工資。稅檔表適用於全年的總工資，所以大額一次性付款可以將該年收入的一部分推入更高檔。

這包括EOBI、公積金或其他工資扣除嗎？

不。此計算器僅計算所得稅，所以所示淨數字是您的工資減去所得稅。任何EOBI或基金扣除在您的實際工資單中分開扣除。

有效稅率是什麼意思？

您的總稅除以您的總工資。它總是低於您的最高檔費率，因為您工資的較低部分按較低檔費率徵稅 — 在上面的例子中，最高檔是25%，但有效稅率是11.56%。

舊附加費在非常高工資時有多大？

在每月Rs 1,000,000（每年Rs 12,000,000）時，稅年2025-26給出Rs 3,685,290含Rs 304,290附加費，而2026-27給出Rs 3,174,000無附加費 — 每年差Rs 511,290。

我的工資在年中改變 — 我輸入什麼？

輸入整個稅年的總工資（將每個費率的月份加在一起）。稅檔適用於年度總計，這就是為什麼此計算器首先以年度數字工作。

前Rs 600,000總是免稅嗎？

是，在本頁兩年中。0%檔涵蓋每個受薪人士的前Rs 600,000；1%稅率僅適用於Rs 600,000和Rs 1,200,000之間的部分。
