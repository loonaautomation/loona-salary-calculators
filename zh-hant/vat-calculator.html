它如何計算

To add VAT：VAT = 淨收入 × 費率 ÷ 100，總收入 = 淨收入 + VAT。要 刪除VAT：淨收入 = 總收入 ÷ (1 + 費率 ÷ 100), VAT = 總收入 − 淨收入。從不將總價內的VAT計算為總收入的直接百分比 — 按19%，€119內的VAT是€19，而不是€22.61。

常見問題

VAT是什麼，如何計算？

VAT（增值稅）是按淨價百分比收取的消費稅。VAT金額 = 淨金額 × 費率 ÷ 100，總（含VAT）價格 = 淨收入 + VAT。此計算器為30個歐洲國家的標準費率做該數學。

如何向價格新增VAT？

選擇國家，輸入淨金額，選擇新增VAT。例如，德國€100淨價按19%給出€19 VAT和€119總價。結果表並排顯示淨收入、VAT和總收入。

如何從含VAT價格中刪除VAT？

選擇刪除VAT（或使用專用反向VAT計算器）。計算器將總金額除以1 + 費率 ÷ 100: 德國€119總價按19%是€100淨收入加€19 VAT — 您不能透過簡單取總收入的19%找到VAT。

我應該使用哪個費率 — 標準還是降低？

大多數日常商品和服務使用國家選擇器中顯示的標準費率。降低費率僅適用於特定類別如食品、書籍、藥品或客運，它們因國家而異 — 本頁費率表列出每個國家的降低費率。如果有疑問，在專用國家頁面上檢查專案。

本頁費率是最新的嗎？

是。每個標準費率於2026年十一月對照官方來源驗證 — 歐洲委員會、GOV.UK、瑞士聯邦稅務局和Skatteetaten。這包括最近改變：愛沙尼亞現在24%（自2025年七月1日起），芬蘭25.5%，羅馬尼亞21%，斯洛伐克23%。

它如何運作 — 公式

計算器將每個國家的標準VAT費率儲存為百分比。在新增模式中，它將您的金額視為淨價：VAT = 金額 × 費率 ÷ 100，總收入 = 金額 + VAT。在刪除模式中，它將您的金額視為總價：淨收入 = 金額 ÷ (1 + 費率 ÷ 100)，VAT = 總收入 − 淨收入。結果四捨五入到兩位小數顯示，含您選擇的國家的貨幣符號。降低費率在上表和每個國家頁面上列出供指導，但計算器本身始終使用標準費率 — 適用於大多數商品和服務的費率。

常見問題

為什麼VAT費率在歐洲差異如此之大？

每個國家在歐盟最低規則內設定自己的費率（標準費率至少15%)。這就是為什麼盧森堡收取17%，匈牙利27%，大多數國家在19%到25%之間。瑞士 (8.1%) 和英國 (20%) 完全在歐盟系統外設定費率。

當我向另一個歐盟國家銷售時，VAT適用嗎？

通常VAT在客戶國家對跨境B2B和許多B2C服務收取，通常透過反向收費機制或歐盟一站式商店 (OSS)。此計算器按所選國家的費率計算金額；哪個國家的費率在法律上適用取決於供應型別，所以對定期跨境貿易尋求建議。
