MwSt.-Nummern-Prüfer

Prüfen Sie, ob eine MwSt.-Nummer dem offiziellen Format ihres Landes folgt — alle 27 EU-Staaten plus das Vereinigte Königreich, die Schweiz und Norwegen. Wichtig: Dies prüft nur das Format, nicht die Registrierung. Die Registrierung kann nur auf den unten verlinkten offiziellen Diensten bestätigt werden.

Kurz gesagt: wählen Sie das Land, geben Sie die Nummer ein, und dieser Prüfer normalisiert sie (Leerzeichen, Punkte und Bindestriche werden entfernt, Großschreibung) und prüft sie anhand des veröffentlichten Mehrwertsteuermusters dieses Landes. „Format looks valid“ bedeutet, die Form stimmt — es not bedeuten, dass die Nummer registriert ist. Prüfen Sie die Registrierung kostenlos beim offiziellen VIES-Dienst.

Wie sie berechnet wird

Hier gibt es keine Rechenoperation — Umsatzsteuernummern werden für jedes Land anhand eines veröffentlichten Musters geprüft:

  • Normalisieren: Leerzeichen, Punkte und Bindestriche werden entfernt und die Nummer wird in Großbuchstaben umgewandelt; das passende zweibuchstabige Länderpräfix wird entfernt, wo ein Land eines verwendet (die Schweiz behält ihr CHE-Präfix; Norwegens MVA-Suffix und die TVA/IVA/MWST-Suffixe der Schweiz werden entfernt).
  • Mustertest: die übrigen Zeichen müssen exakt mit dem Format des Landes übereinstimmen — zum Beispiel ist Deutschland neun Ziffern, Frankreich sind zwei Buchstaben oder Ziffern gefolgt von neun Ziffern, die Niederlande sind neun Ziffern, der Buchstabe B, dann zwei Ziffern, und Malta sind sechs Ziffern gefolgt von zwei Buchstaben.
  • Ergebnis: das Ergebnis gibt klar an, ob das Format für das gewählte Land gültig aussieht, und erinnert Sie daran, dass Format keine Registrierung ist.

Durchgerechnete Beispiele — jedes Ergebnis unten wird beim Laden der Seite von der eigenen Prüfung dieser Seite ausgefüllt, sodass es niemals von der Prüfung oben abweichen kann:

  • Deutschland, DE123456789 → wird geprüft…
  • Deutschland, DE123 (zu kurz) → wird geprüft…
  • Frankreich, FR40303265045 → wird geprüft…
  • Niederlande, NL123456782B12 → wird geprüft…
  • Vereinigtes Königreich, GB123456789 → wird geprüft…

Häufig gestellte Fragen

Bestätigt dieser Prüfer, dass eine MwSt.-Nummer registriert ist?

Nein. Dieser Prüfer validiert nur das Format — ob die Nummer dem offiziellen Muster für ihr Land folgt. Er kann nicht bestätigen, dass die Nummer registriert oder aktiv ist oder zu einem bestimmten Unternehmen gehört. Verwenden Sie zur Registrierungsprüfung den offiziellen EU-VIES-Dienst oder für britische Nummern den Prüfer der Regierung des Vereinigten Königreichs.

Was ist VIES und wann sollte ich es verwenden?

VIES (VAT Information Exchange System) ist der kostenlose offizielle Dienst der Europäischen Kommission, um zu prüfen, ob eine EU-Umsatzsteuernummer für den grenzüberschreitenden Handel registriert ist. Verwenden Sie ihn, bevor Sie einen EU-Geschäftskunden zum Nullsatz besteuern. Diese Seite verlinkt direkt unter dem Prüfer auf VIES.

Warum ist eine echte Umsatzsteuernummer bei dieser Formatprüfung durchgefallen?

Meistens wegen Tippfehlern: zusätzliche Buchstaben, ein fehlendes Länderpräfix, wo eines erforderlich ist, oder die falsche Anzahl von Ziffern. Prüfen Sie das für das Land angezeigte Muster, entfernen Sie Leerzeichen und Satzzeichen und versuchen Sie es erneut. Wenn das Format korrekt ist, Sie aber Gewissheit über die Registrierung brauchen, prüfen Sie dies in VIES.

Gebe ich die Länderbuchstaben am Anfang der Nummer ein?

Beides funktioniert hier. Dieser Prüfer entfernt das zweibuchstabige Länderpräfix automatisch, wenn es mit dem von Ihnen ausgewählten Land übereinstimmt, sodass für Deutschland sowohl DE123456789 als auch 123456789 akzeptiert werden. Die Schweiz ist die Ausnahme: Schweizer Nummern behalten ihr CHE-Präfix.

Wie prüfe ich die Registrierung einer britischen USt-Nummer?

Format und Registrierung sind auch im Vereinigten Königreich getrennt. Verwenden Sie nach dieser Formatprüfung den offiziellen Dienst der britischen Regierung — Check a UK VAT number — der unten beim Prüfer verlinkt ist und bestätigt, ob eine UK-Nummer registriert ist, und den Namen des Unternehmens anzeigt.

Datenschutz: dieser Prüfer läuft zu 100% auf Ihrem Gerät — die Umsatzsteuernummer, die Sie eingeben, verlässt niemals Ihren Browser. Haftungsausschluss: nur Formatvalidierung anhand der veröffentlichten nationalen Muster für Umsatzsteuernummern; sie kann eine Registrierung nicht bestätigen. Muster im November 2026 anhand der von der Europäischen Kommission veröffentlichten Formate für Umsatzsteuernummern überprüft; für die Registrierung verwenden Sie den offiziellen VIES-Dienst (ec.europa.eu/taxation_customs/vies) oder, für UK-Nummern, gov.uk/check-uk-vat-number.

Wie es funktioniert — die Formel

Jede europäische Steuerbehörde veröffentlicht die genaue Form, die ihre MwSt.-Nummern haben müssen: wie viele Zeichen, welche Positionen Ziffern und welche Buchstaben sind, und in einigen wenigen Fällen feste Buchstaben wie das B in niederländischen Nummern oder das U am Anfang österreichischer Nummern. Eine Formatprüfung ist daher ein Musterabgleich, keine Berechnung: Normalisieren Sie die Eingabe, entfernen Sie das Länderpräfix und prüfen Sie, was übrig bleibt, gegen das Muster dieses Landes. Ein Bestehen beweist nur, dass die Nummer in dieser Form existieren könnte — eine falsch eingetippte Ziffer innerhalb einer korrekt geformten Nummer oder eine korrekt geformte Nummer, die nie ausgestellt wurde, kann nur eine offizielle Registrierungsdatenbank wie VIES erkennen.

Rechenbeispiel

Nehmen Sie das deutsche Beispiel DE123456789. Das Normalisieren entfernt nichts außer dem DE-Präfix, sodass übrig bleibt … — neun Ziffern, was exakt dem deutschen Muster entspricht, das Ergebnis lautet also, dass das Format für Deutschland gültig aussieht. Dieselbe Nummer, gekürzt auf DE123, lässt nur drei Ziffern übrig und fällt durch, wie das zweite durchgerechnete Beispiel oben zeigt. Keines der beiden Ergebnisse sagt etwas über die Registrierung aus: Dieser letzte Schritt gehört immer zu VIES (oder zum UK-Prüfer für eine GB-Nummer).

Häufig gestellte Fragen

Welches Format hat eine deutsche Umsatzsteuernummer?

Eine deutsche Umsatzsteuer-Nummer (USt-IdNr.) besteht aus genau neun Ziffern, zum Beispiel DE123456789 nach ihrem DE-Präfix. Sie unterscheidet sich von der inländischen deutschen Steuernummer, die ein anderes Format hat und nicht für den grenzüberschreitenden EU-Handel verwendet werden darf.

Warum erlauben einige Länder mehr als ein Mehrwertsteuerformat?

Einige Länder geben mehr als ein Muster aus — Irland und Spanien haben jeweils ältere und neuere Muster, und Litauen gibt 9-stellige Nummern an juristische Personen und 12-stellige Nummern für vorübergehende Registrierungen aus. Dieser Prüfer akzeptiert jedes veröffentlichte Muster für das ausgewählte Land.

Kann ich mich für die Rechnungsstellung auf eine Formatprüfung verlassen?

Eine Formatprüfung ist eine nützliche erste Kontrolle gegen Tippfehler, aber für zum Nullsatz besteuerte EU-Lieferungen sollten Sie den Nachweis einer VIES-Registrierungsprüfung mit ihrer Konsultationsnummer zusammen mit der Rechnung aufbewahren. Das Format allein ist kein Nachweis dafür, dass Ihr Kunde umsatzsteuerlich registriert ist.
