Wie es funktioniert — die Formel

Die Einkommensteuer wird progressiv berechnet: 12.5% auf Einkommen von 0 bis 8,342; 15.7% auf Einkommen von 8,342 bis 12,587; 21.2% auf Einkommen von 12,587 bis 17,838; 24.1% auf Einkommen von 17,838 bis 23,089; 31.1% auf Einkommen von 23,089 bis 29,397; 34.9% auf Einkommen von 29,397 bis 43,090; 43.1% auf Einkommen von 43,090 bis 46,566; 44.6% auf Einkommen von 46,566 bis 86,634; 48% auf Einkommen von 86,634 und darüber. Die ersten €4,587.00 sind steuerfrei. Sozialbeiträge: 11.00% des Bruttogehalts. Das Nettogehalt ist das Brutto minus Einkommensteuer und den modellierten Sozialbeiträgen. Dies ist eine Schätzung für einen alleinstehenden Erwerbstätigen ohne anderes Einkommen und ohne Angehörige — Ihr tatsächliches Gehalt kann abweichen.
